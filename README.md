
# DocuMind AI
## AI-Based Document Question Answering System

### 1. Project Overview
DocuMind AI is a web-based document question answering system developed using Python and Flask.

It allows users to upload documents, extract information, build a knowledge base, and ask questions based on the uploaded content.

### 2. Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- VS Code

### 3. Main Features
- Document Upload
- Text Extraction
- Knowledge Base Construction
- Question Processing
- Information Retrieval
- Answer Generation
- System Evaluation

### 4. AI Techniques Used
The system uses keyword matching, search, and rule-based information retrieval.

It identifies matching words between user questions and stored document sentences to retrieve relevant information.

NLP and RAG techniques are not used.

### 5. How to Run the Project

1. Open the project folder in VS Code.
2. Activate the virtual environment.
3. Run the command:

python app.py

4. Open the browser.
5. Visit http://127.0.0.1:5000

### 6. Conclusion
DocuMind AI provides a simple interface for document-based question answering and demonstrates knowledge representation and search-based information retrieval.
